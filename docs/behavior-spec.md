# Behavior specification — Netflix Shortcut Override

Status: Active
Date: 2026-10-25

This document defines observable product behavior. Domain terms have the meanings established in [`CONTEXT.md`](../CONTEXT.md); implementation structure and historical design decisions are outside this specification.

## Shortcut key conflicts

- Conflict checks are scoped to each table and compare physical key codes plus modifiers. Individually disabled rows retain their saved keys but release them for reuse within the table. Individually enabled rows reserve their keys even while the global or subtitle master is off. Unsupported Firefox Picture-in-Picture does not reserve a key.
- Enabling a row or restoring its default key must not silently create an enabled duplicate. If the proposed key belongs to enabled peers, show a popover anchored to the row switch and leave all settings unchanged. Identify the key and every affected action, and explain that transferring disables those actions.
- **Change key** opens the existing recorder. A valid, conflict-free save sets the key and enables the requesting row; cancellation preserves settings. **Use for [action]** enables the requesting row and disables all enabled peers using that key in one settings update, preserving their saved keys and the other table.
- Escape or clicking outside dismisses the popover without saving. Keyboard focus returns to the row switch on dismissal and after closing the recorder opened from it, provided the switch is still available. External settings changes dismiss a pending conflict so old choices cannot reappear.
- Section resets restore unique defaults within their own table. Cross-table overlaps retain subtitle navigation priority; the popover does not transfer keys across tables.

## Compatibility session

- A tab whose load status is `loading` remains in the checking state and does not publish compatibility diagnostics.
- After ten seconds of continuous loading, the popup explains that compatibility will be checked automatically when loading finishes. The extension never reloads the page automatically.
- Each `loading` or `complete` transition starts a new diagnostics generation. A response from an older generation cannot overwrite the current state.
- While the popup remains open, incomplete or unavailable playback diagnostics are checked again roughly every two seconds, including when the diagnostics dialog is closed. The pending header message clears when playback becomes ready. Missing content-script receivers use the bounded retry policy; ready core playback and reload-required results stop automatic retries. Closing the popup or starting a new load generation cancels the prior observation.

## New feature announcement

Implementation reuse is described in [Reusing feature announcements](feature-announcements.md).

- Subtitle navigation remains opt-in. Only an extension update from a version before `0.6.3` to `0.6.3` or later creates its announcement, including skipped releases. First installation, reinstallation, browser updates, and same-version development reloads do not create it. An unread eligible announcement shows `NEW` on the extension icon and in the popup introduction. Once the loaded, visible popup renders that introduction, it records the announcement as seen and clears `NEW` without enabling the feature. A loading or hidden popup does not count as viewing. The current visit keeps the introduction readable until dismissed, navigated away from, or activated; subsequent popup visits hide the seen introduction. The subtitle navigation master and bindings are managed in Options; the popup provides a read-only reference.
- **Go to enable** on the introduction retires the announcement and opens the settings page, scrolls to the subtitle navigation section, and moves keyboard focus there. While subtitle navigation is off, a popover anchored to the settings-page master switch shows a brief activation guide and website-access explanation. The switch's visible label is **Enable**. With the global override off, the popover explains that prerequisite first. Clicking the switch does not dismiss the popover while permission is pending or denied. Clicking elsewhere, pressing Escape, or successful activation closes it. Normal settings-page visits do not open it. The Sentence jumps and replay heading has no information button or tooltip. Navigation does not enable the feature or request permissions.
- Successful persisted activation or explicit dismissal clears both the announcement and badge. Denied permissions or failed settings saves do not restore a viewed introduction or badge; retry remains available in Options. A failed dismissal shows a retryable error. If recording a view fails, the badge remains unread and viewing the introduction again retries.
- Local eligibility, seen state, and acknowledgement keyed by feature ID survive browser restarts and extension updates. An unread announcement remains available through later updates, but those updates never recreate a viewed badge or dismissed announcement. Disabling an activated feature does not show the same announcement again. Announcement state is separate from synced settings and settings backups and is cleared by uninstalling.
- Updates never automatically open a tab or show an operating-system notification for this announcement.

## Playback focus restoration

- Passive popup dismissal delegates focus restoration to the background service worker.
- A request remains pending for at most 30 seconds while the same active, visible playback context finishes loading and reports fresh readiness.
- Changing tab or window, closing the tab, or leaving the playback context cancels the request.
- Once eligible, the page receives at most three `window.focus()` attempts, 100 milliseconds apart, and reports whether focus was acquired.
- The extension does not focus the HTML video element, Netflix player element, or document body.
- Restart-safe pending state contains only the tab ID, window ID, an opaque request ID, and a deadline.

## PiP session and video selection

- A PiP session uses Document Picture-in-Picture and retains only one Netflix playback session. The adopted video mirrors that session's visuals and events without creating another session.
- Initial entry considers every attached video in the current playback context. Recoverable replacement considers every attached video in its connected current or remembered Netflix player roots, excluding the adopted video while it remains in PiP.
- The complete candidate set is ranked globally, in this order: a current frame, active playback, valid intrinsic dimensions, then larger rendered area.
- Player-root preference may break a tie, but it cannot allow a lower-ranked candidate in an old root to beat a higher-ranked candidate in another eligible root.
- The user may resize the browser-owned PiP window. The video preserves its aspect ratio and uses black bars rather than stretching when the window ratio differs.
- The preferred initial width is 640 CSS pixels; initial height follows the adopted video's intrinsic or rendered aspect ratio.
- Netflix layout or style changes must not dislodge the adopted video from the PiP viewport. Restoring the video must also restore its original source placement and inline presentation.

## PiP timeline and transport controls

- The PiP timeline reads media state for display and submits seek requests through the Netflix playback session. It never assigns native `video.currentTime`.
- A timeline click submits an immediate absolute position. Keyboard seeking submits a relative movement from the current position.
- During a drag, the timeline previews locally and submits one seek when the pointer is released.
- After submission, the requested position remains visible while stale media events are ignored. Normal updates resume when Netflix reports the requested position.
- A rejected request or a three-second confirmation timeout restores the latest reported media position.
- A timeline seek may restore playback if the episode was playing or had ended when the seek was submitted. A newer extension playback or seek command cancels that deferred restoration. Closing PiP, replacing its adopted video, starting another timeline interaction, or disabling the extension also invalidates it; re-enabling does not revive it. A failed seek never starts playback.
- Releasing or cancelling a timeline interaction returns focus to the PiP document so the next configured shortcut can be handled.
- Playback-control state follows reported Netflix playback events; it does not assume a requested command succeeded.
- The first primary click on the PiP video requests play or pause while allowing the browser to focus the PiP window. Timeline clicks do not trigger this video-click action.
- Controls overlay the video and hide after three seconds of pointer inactivity. Shortcut feedback remains a separate transient overlay.

## Configurable seeking and episode shortcuts

- Previous/next frame default to comma/period. A playing video is paused through the Netflix player API before moving one frame and remains paused afterward. Already-paused video steps directly. Frame duration comes from Netflix diagnostics when available, with a documented 24 FPS estimate otherwise. Repeats accumulate target positions even when tiny seeks or intermediate completions have not caught up. Targets clamp to the video duration. Playback, ordinary seeks, video replacement, and watch/session changes invalidate the accumulated position. The Netflix seek API controls the rendered result; exact frame accuracy is not guaranteed when Netflix rounds seeks.
- General settings includes Hide pause overlay, off by default for fresh and upgraded settings. Its explanation appears in the information tooltip, accessible by pointer and keyboard focus. When both this preference and the global override are enabled, the source watch player hides Netflix's idle evidence overlay (title, synopsis, paused label and dark backdrop) during ordinary pauses and frame stepping, including overlays inserted later. This applies independently of how playback was paused and continues across repeated pauses and replacement watch players. Captions, transport controls, errors and content outside the watch player remain visible. The presentation changes no playback state or position. Changes apply immediately without a reload. Disabling either switch removes the stylesheet; the independent preference is retained through global-disable cycles. Settings search includes its labels and description in all interface languages; backups and legacy compatibility recovery retain the preference.
- Previous/next audio language default to Shift+A / Shift+D, use the available Netflix audio track catalog in its original order, and wrap at both ends. Audio hints translate the track's language into the extension interface language, omit original-audio markers, and retain a localized audio-description label when applicable. Traditional Chinese uses 日語 for Japanese audio. If the language tag is missing, invalid or unknown, hints fall back to Netflix's track name with recognized original-audio markers removed. Track IDs distinguish variants sharing a language. A sole selected track is not reselected; no available tracks or failed switching produces localized feedback. Audio key repeats are consumed without switching again. These actions are listed under Volume; frame actions are listed under Playback.
- Schema v26 adds the four built-in bindings. Upgrading enables each only if its default key is not already owned by an enabled saved binding, including custom shortcuts. Backups through v25 remain importable; v26 backups require all four bindings.

- Options shows one page at a time in a shadcn Sidebar layout. The shortcut pages are Playback, Seeking and jumps, Subtitles, Subtitle navigation, Volume and audio, Display, and Playback speed. General settings, Playback automation, and Backup and restore are separate pages in the settings group. The global enable switch stays at the top of the desktop sidebar and appears above content on narrow windows. Narrow windows use a Sheet navigation drawer that closes after selecting a page. Page selection and subgroup expansion never change saved settings. Subtitle navigation retains its own master, permission flow, and reset; its introduction link selects that page, clears search, and focuses its section after rendering.
- Search in Options and the popup matches action and category names in all five interface languages (English, Traditional Chinese, Simplified Chinese, Japanese, and Korean), regardless of the selected interface language. It also matches physical key codes, displayed keys, and modifiers across shortcut pages, including subtitle navigation, custom seek, and subtitle-size entries. Queries can combine translated names with keys, and ignore letter case and full-width character differences. Search results show matching rows under their category headings and expand matching subgroups without disclosure controls. Clearing search or pressing Escape restores the selected category; choosing a category also clears search. Editing a key that removes its search result returns focus to search.
- Favorite audio tracks is optional and starts empty. Up to 20 language/Audio Description pairs are saved in user order. Standard and description variants appear as separate choices in the same picker and can be added together without a mode switch. Audio cycling picks one matching available track per favorite, reserves exact and regional matches before generic language matches, skips unavailable favorites, and leaves the current selection unchanged with localized feedback if none match. An empty list preserves the full Netflix catalog order. Favorites never cause an automatic audio change when opening a title. Settings, backups, Chromium page events and Firefox serialized execution preserve both the order and the description preference.
- Options additionally searches settings-section titles and field labels in all five interface languages: favorite subtitles, favorite audio tracks, speed range and step, hold-speed hints, seek seconds and percentage groups, subtitle-navigation activation, general settings, playback automation, and backup/restore. Matching sections remain directly editable, and empty percentage groups expose their Add control. Favorite subtitles also matches the names and aliases of saved languages. Speed-range results appear independently of speed-shortcut rows.
- Options and the popup share the shortcut search index, function aliases, and matching rules. Language names and aliases such as 日語, 일어, and US English find the previous/next subtitle-language and audio-language shortcuts. Function aliases such as resume, floating player, and 畫中畫 find their corresponding actions. Language names do not select a track or imply that the video offers that language. Both kinds of alias can be combined with a key or modifier.
- The favorite-subtitle language picker searches names in all five interface languages, native language names supplied by the browser, language codes, and common aliases in multiple languages, such as 日語／日文, 韓語／韓文, US English, 仏語, 일어, 불어, and Farsi. Base-language aliases also match regional variants; script and region aliases match only their specific variants (for example, 繁中／번체자 and 简中／간체자). Result labels follow the selected interface language; aliases select the same saved language, and selections remain pending across searches until Add is chosen.
- Every shortcut editor supports an explicit Clear shortcut control and saving an empty key. Empty keys display as Not set, reserve no key, trigger no shortcut, and do not suppress the original Netflix key. Clearing preserves the row’s enabled preference and all numeric values. Cancel discards the draft. Schema v27 stores an unassigned key as null and preserves it through normalization, synchronization, and backup export/import; missing or malformed keys remain invalid in backups. General, subtitle-navigation, custom seek and subtitle-size bindings all support this state.
- Ordinary shortcut keys are clickable edit buttons; pencil edit, row switches and reset controls remain visible. Favorite subtitles starts expanded; its heading shows the title without a saved-count indicator. Play / Pause hold speed is an expanded nested table directly below Play / Pause, titled Hold, with Speed, Enabled, Hint, and Action columns. It shares that shortcut's key without repeating it in the nested table. The Hint switch saves immediately. Edit opens a Save/Cancel dialog for the speed draft and preserves the latest hint preference. The Enabled switch is disabled when Play / Pause is disabled; Hint and Edit are also disabled when hold speed is off. Reset restores only hold-speed settings.
- Seeking and jumps contains Forward/rewind and Jump to position as independent, initially expanded subgroups. Forward/rewind uses one table with Seconds, Rewind shortcut, Forward shortcut, Enabled, and Actions columns; each interval is one row with no additional nesting. Both subgroups have a short Add button in their header, separate from the disclosure button and available while collapsed. Add expands the subgroup and opens the shortcut modal. Switching categories preserves these subgroup expansion states.
- Playback speed shows its shared minimum, maximum, and adjustment amount in a separate Range and step card below the shortcut card. The three fields are edited directly in the card and save automatically on blur, Enter, or a completed label drag; their reset preserves preferred speed. Preferred speed is shown in its shortcut row and edited with its key in one Save/Cancel dialog. Add preferred speed creates additional groups, each with an independent speed, optional key, enable switch, edit and delete actions. New groups are created only on Save. Numeric-field keystrokes do not record shortcuts. Cancel discards both drafts, Restore restores both saved drafts, and the original row reset restores both defaults. A preferred-speed or binding change elsewhere blocks saving the stale editor until reopened. All groups support shortcut search and appear in the popup; held-key repeats do not reapply them, and explicit speed changes cancel a temporary hold speed. Resetting all shortcuts removes additional groups. The range card is a sibling of the shortcut card, and hold-speed controls remain nested under Play / Pause. The popup provides shortcut reference and links to Options for editing preferences.
- A forward/backward pair shares one interval (1–3600 whole seconds), one enable switch, and one editor. The modal edits seconds and both keys together; a percentage modal edits progress (0–100 whole percent) and its key together. Numbers and keys stay local until Save applies the complete entry in one update. Cancel or Escape discards edits and returns focus to the initiating button. Restore restores the saved number and keys. Dragging the numeric label horizontally adjusts the modal value by one second or five percentage points per eight pixels, clamps to its allowed range, and restores the starting draft on pointer cancellation. Releasing a drag keeps the change local until modal Save. Direct numeric entry remains available. Number input never records shortcuts; focused key fields record independently and allow Tab navigation. The table displays saved values without inline numeric inputs.
- Assigned pair keys must differ; either or both key fields may be empty. Conflict validation ignores both saved keys of the pair being edited, allowing them to be swapped, and checks enabled assignments outside the pair. A pair switch enables or disables both directions together. Enabling a conflicting pair requires explicit key transfer or changing the keys. Transferring a key away from a pair disables both directions. Existing legacy partial pairs appear active when either direction is enabled; toggling or saving their editor applies one common enabled state. Editing a disabled row preserves its disabled state. Modal Save is disabled if another view changes or deletes that entry while it is being edited. Subtitle navigation retains priority over custom keys.
- The original left/right interval uses the same modal (1–60 seconds) on the options page. The popup lists custom shortcuts in its reference; General settings in Options contains only language, interface style, and brightness. Playback-rate settings are independent of seeking.
- Percentage seeking requires a finite, positive video duration and submits an absolute position through the Netflix playback session, never by assigning `video.currentTime`. Percentage and episode actions ignore held-key repeats; relative seeking can repeat. Editable text fields retain their normal typing behavior.
- Previous/next episode shortcuts default to Ctrl+P / Ctrl+N and can be remapped. Next uses Netflix’s next control; previous opens Netflix’s episode picker and plays the preceding episode in the current list. Missing controls or an episode boundary report unavailability without guessing a watch ID or using browser history. Deferred picker work is bounded and cancelled when another command takes over, the extension is disabled, or the watch path changes. Browser-reserved combinations may require remapping.
- Schema v22 preserves existing preferences and introduces an empty custom-seek list. New episode bindings are disabled on upgrade when an enabled saved general binding already owns their default key. Current backups require valid custom values, unique IDs and complete bindings; supported older backups migrate without adding custom rows. Resetting general shortcuts clears custom rows and restores built-in defaults.
- Schema v23 stores one positive interval per seek pair and requires both directional bindings in current backups. Migrating v22 combines opposite saved directions with equal intervals while preserving keys and enabled states. An unpaired direction retains its key and state, and its new counterpart starts disabled.
- A seek editor draft that would exceed synchronized settings capacity stays open with Save disabled and a localized explanation. Removing a custom shortcut frees capacity. The check includes the complete stored settings and compatibility aliases; oversized imports and other writes fail before replacing saved preferences.

## Shortcut feedback

- Successful frame hints use the existing icon-only playback surface, with a directional single triangle and vertical bar to distinguish stepping from fast-forward/rewind. They do not show previous/next frame text. Audio-language hints use the existing compact subtitle-media hint sizing: 12px labels, 12px × 20px padding, and the same icon scale. Subtitle-language and audio-language hints stay visible for 1 second after their latest update before fading. Other hint durations retain their existing timing.

- A handled shortcut may show transient visual feedback without taking focus or blocking playback interaction.
- Repeated volume or speed actions update the visible feedback in place. Repeated seeks in the same direction accumulate during the feedback window; changing direction starts new feedback.
- Play / Pause hold feedback remains visible while hold speed is active and disappears after release.
- Using Increase Speed, Decrease Speed, Preferred Speed, or Reset Speed while hold speed is active ends the hold interaction immediately. Its hint disappears, the explicit speed command becomes the new persistent speed, and releasing Play / Pause does not restore the pre-hold speed or toggle playback.
- Feedback shown in the PiP window scales with the window, stays within the video viewport, and remains visually separate from mirrored subtitles and transport controls.

## Playback automation

- Intro and recap skipping are separate preferences, both off by default. They require the global extension switch to be on.
- On a Netflix watch page, automatically click a recognized, visible and enabled intro or recap button only when its preference is enabled. Wait for an in-progress seek to finish before clicking. Record the skip after a forward seek completes. If the seek is unconfirmed and the corresponding button remains available after the confirmation window, try once more. Rewinding into a skipped segment or changing episodes allows another skip. Credits and next-episode buttons do not trigger either preference.

- Auto next episode is an independent preference, off by default, shown below intro and recap in the playback automation section in Options. It requires the global extension switch. On a watch page with a video, it clicks only a visible, enabled Netflix end-card next-episode control (`next-episode-seamless-button` or `next-episode-seamless-button-draining`), never the ordinary transport next button, recommendations, or credits-only controls. While enabled, it also checks visibility every 100 ms (with the existing 50 ms scan scheduling delay), so CSS entrance animations do not have to finish before the first click. It waits for seeking to finish and retries at most once after 1.2 seconds. Changing watch IDs resets the attempt limit; a lingering button already used for the previous watch ID is ignored. Disabling either switch cancels pending work. This does not change Netflix profile autoplay settings.

## Netflix subtitles

- The subtitle-size shortcut defaults to `Shift + V` and cycles 80% → 100% → 125% → 80%, ignoring held-key repeats. The subtitle-size shortcut is a regular row in the Subtitles table, with no nested subgroup or Add shortcut control. Its pencil opens the existing editor for the cycle and key. Previously saved custom fixed-size or cycle shortcuts remain in the same table and can be edited or removed. Each size is an integer from 50% to 300%; new cycles contain 2–6 unique sizes in the user’s saved order. Existing cycles with up to 12 sizes remain readable, editable and supported by backups, but cannot grow beyond their saved count; adding sizes stops at six. Dragging a row’s handle reorders the cycle; the handle also supports ArrowUp / ArrowDown. Dragging a numeric label still changes its percentage. A press selects the next entry and wraps from the last to the first. If the current size is outside the cycle, its next press selects the first entry. Each editor saves sizes and its shortcut together, checks enabled-binding conflicts and storage capacity, and explains that percentages scale the video’s original subtitles rather than specifying an absolute font size. Regular playback and PiP remember their current sizes separately. 100% restores original caption typography, and disabling the extension removes the regular playback override. Schema v24 preserves legacy small/medium/large values and bindings, adds the default cycle and an empty custom list, and validates custom sizes and bindings in backups. Schema v25 preserves user-defined cycle order through storage and backup. Upgrades disable the original binding if its default key conflicts with an existing enabled shortcut.
- Queued subtitle-track changes recheck the global and originating row switches and the original watch/video before dispatch. Disabling the extension, cancelling pending actions, closing the originating window, or changing the watch/video discards queued requests. Rapid valid presses remain serialized; discarded requests do not change tracks or show feedback. Already-issued successful PiP commands still retain their confirmed subtitle fallback state.
- The configurable subtitle shortcut toggles the active Netflix playback session's native subtitle track.
- Turning subtitles off remembers the selected track. Turning them on restores the same track when it remains available, otherwise it selects the first available non-off track.
- The configurable next and previous track shortcuts default to `Shift + C` and `Shift + X`. Both support regular and CC tracks. Favorites prefer regular subtitles and fall back to CC for the same language. They cycle through the favorite languages in the configured order, or through all subtitle tracks in player order when the favorites list is empty. Next wraps from the last track to the first, and previous wraps from the first to the last. With subtitles off, next starts at the first available subtitle track and previous starts at the last. A missing subtitle match produces a localized hint and preserves the current track. The shortcuts show the selected track name and ignore held-key repeats. Upgrades preserve existing enabled assignments for these keys. Favorites store only languages, and legacy language/type duplicates merge at their first position.
- A successful shortcut shows the same subtitle-settings icon used by PiP controls in the standard circular, text-free transient hint. The icon is white when subtitles are enabled and dimmed when they are disabled. If the Netflix subtitle API is unavailable, it reports failure without guessing from transient subtitle DOM content.
- When PiP opens, it reads the active Netflix playback session's native subtitle state and uses that state to initialize the subtitle switch and mirrored-subtitle visibility. The extension's last stored PiP subtitle-visibility value is only a fallback when the Netflix API state is unavailable.
- In PiP, the subtitle switch toggles Netflix's native subtitle track and updates mirrored-subtitle visibility from the API's resulting state. Using the subtitle shortcut inside PiP updates the same switch and stored fallback value. Once a subtitle action is issued from PiP, a successful API result updates the stored fallback even if PiP closes before the result arrives.

## Settings backup and restore

- Export produces a versioned JSON backup containing the complete normalized settings state and source metadata.
- Import validates the backup format, metadata, supported settings version, and every required field for the current settings schema before previewing or writing anything.
- Older supported settings versions may be migrated through the same normalization rules used for synced settings. A newer or malformed settings version is rejected.
- First loading older settings and importing their backups preserve saved keys, row enabled states, and master switches. Newly introduced shortcuts stay disabled when their default key belongs to an enabled saved general or subtitle-navigation row, even when its master is off. Disabled saved rows release their keys.
- When older clients replace synced settings, newer clients retain preferences those clients omitted or could not represent using a separately validated snapshot. Shared edits still apply, and recovered new actions yield to enabled legacy assignments. Current-client saves, resets, and confirmed backup replacements refresh both records so removed preferences cannot return through recovery.
- Import shows a summary and requires explicit confirmation before replacing current settings. A validation or storage failure leaves the current settings unchanged and reports the failure.
- The import summary separates general shortcut counts from subtitle navigation and shows the subtitle navigation master switch, enabled-key count, and all four configured bindings with their individual enabled states. Export and restore include these settings even when the master switch is off.

## Recoverable video replacement and episode transitions

- Detachment, `error`, `ended`, or `emptied` starts bounded replacement handling. While replacement handling is pending, PiP video clicks are consumed without sending playback commands.
- A different HTML video element is not, by itself, evidence of an episode transition.
- After `ended` or `emptied`, a replacement element confirms an episode transition only when it was not observed in the candidate set before the boundary. A sibling video observed before the boundary cannot confirm a transition, but it may remain eligible as a recoverable replacement.
- Reuse of the adopted video confirms an episode transition only when playback previously advanced beyond 30 seconds, restarts at or before 30 seconds after the boundary, and the restart was not caused by an observed user seek.
- An `emptied` event starts a new media-resource boundary and supersedes seek evidence recorded before that event. A seek observed after the boundary still prevents a playback reset from being classified as an automatic episode transition.
- A confirmed episode transition closes PiP without activating or focusing the Netflix playback context. PiP cleanup does not pause, resume, or otherwise override the next episode's playback state; with Auto next episode off, autoplay follows Netflix and the active profile setting consistently in Chrome and Edge. The independent Auto next episode preference can click the end-card control to advance. If a distinct next-episode video already owns the source playback context, the obsolete adopted video is released with the PiP window instead of being restored beside it; if Netflix reuses the adopted video for the next episode, that video is restored normally.
- After PiP closes, the source page must show the next title and expose working playback, seek, volume, episode, audio/subtitle, and fullscreen controls regardless of whether Netflix leaves the episode playing or paused.
- A replacement without sufficient episode-transition evidence is recoverable. The PiP session adopts the best presentation-ready candidate and keeps the same PiP window open.
- The PiP session remembers the last valid intrinsic dimensions across a recoverable replacement. A candidate without metadata temporarily uses that aspect ratio until valid replacement dimensions arrive.

## Recovery limits and cleanup

- If no usable presentation-ready candidate appears within eight seconds, the PiP session closes instead of leaving a permanent black window.
- A recovery cycle starts when the adopted video is detached, fails, or is replaced, and completes when that video recovers or another video is adopted.
- Three recovery cycles started within a rolling five-second window are considered unstable, even if every cycle completes successfully. The PiP session closes on the third cycle; after five continuous seconds without another cycle, earlier cycles no longer count.
- Normal click controls resume when the adopted video recovers without an episode transition.
- Explicit exit, PiP-window `pagehide`, destruction, leaving the playback context, or manually changing the source tab to a different `/watch/<id>` restores the currently adopted video and closes PiP. Manual episode selection does not pause playback in the source tab. Query-string changes for the same watch ID do not end the PiP session.
- Cleanup is idempotent. Late events from an old video or closed PiP session cannot change current bindings or visible state.

## Validation boundary

Automated tests verify extension behavior against controlled browser and Netflix-player substitutes. They do not prove production Netflix element identity, player-session ordering, event timing, or episode-navigation behavior; those remain real-browser acceptance checks.

## Page feature management

- Each shortcut section has an icon-only Manage page features button at the top right. It opens a popover checklist containing feature names and checkboxes, with no edit, reset, delete, or add controls. Unchecking immediately hides the corresponding settings row as a local preview. Apply saves the hidden and disabled states; Cancel, Escape, outside dismissal, or navigation discards the preview.
- Unchecking hides and disables a feature while retaining its configured keys and parameters. Hidden items are omitted from Options and Popup, including search, and remain available in the management checklist. Row switches can still disable a visible feature independently.
- Seek pairs have one checkbox for both directions. Each custom seek, preferred speed, and subtitle-size combination has its own entry. New entries start enabled. Checking a hidden entry shows it again and enables it only when its key is unoccupied. Conflicting entries stay disabled with their saved keys intact, and existing key owners are unchanged. A seek pair stays disabled if either direction conflicts. Rechecking does not open the transfer prompt; a visible row can still be enabled through its ordinary conflict workflow. Parent subtitle navigation and Play / Pause dependencies preserve child selections when off; their settings remain visible.
- The checklist has Apply and Cancel buttons and hover backgrounds on checklist rows. There is no Undo notification. Visibility and automatic enable/disable decisions remain local until Apply. External feature changes disable Apply until the menu is reopened; unrelated preference edits are preserved. Failed writes use the existing confirmed-settings rollback and error display.

## Subtitle navigation shortcuts

- Subtitle navigation has a master switch, off by default, plus independently enabled and editable bindings. Default keys are A (previous), D (next), and W (play/pause). Replay starts unassigned and disabled; saved replay keys and enabled states are preserved.
- Both builds declare Netflix page access as required and `nflxvideo.net` subtitle CDN access as optional. No access to `nflximg.net` or `nflxext.com` is declared or accepted for subtitle delivery. Turning on the subtitle master in Options calls the browser permissions API directly from the user gesture for Netflix and `nflxvideo.net`. Already-granted access proceeds without another prompt. The master remains off and disabled while awaiting approval; denial or failure leaves settings unchanged, displays localized retry guidance, and permits another attempt. Turning the global override off or closing the view that requested access invalidates a pending approval so it cannot later enable the master. Switching Options sidebar pages preserves the pending attempt. Turning the subtitle master off neither requests nor revokes host access.
- Turning off the global shortcut override disables the subtitle navigation controls while retaining their configured master and row states. Inline guidance explains the global-switch dependency.
- The section reset restores the default bindings while preserving its master switch and general settings; default rows whose keys are occupied by enabled general shortcuts remain disabled. Individual row resets restore that row's default key and enabled state: A/D/W enabled, replay unassigned and disabled. Individual row resets remain available while the global override is enabled. With only the subtitle navigation master off, keys can still be edited and reset, but row switches are disabled. The ordinary shortcut reset leaves subtitle navigation unchanged. Both tables use the same column layout. The section title has no information button or tooltip.
- General and subtitle-navigation assignments share enabled-key ownership. Recording, enabling, or resetting a row checks both groups; occupied keys require a different key or explicit transfer. Transfer disables the actual previous owner, including both directions of a seek pair. For legacy/imported overlaps, available enabled general shortcuts handle the key and subtitle rows show Shortcut priority. Unsupported PiP bindings do not block subtitle navigation.
