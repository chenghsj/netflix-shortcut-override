# Microsoft Edge Add-ons search terms

Suggested search terms for each supported store listing language. Enter each
line as a separate term in Partner Center's **Search terms** field.

Limits shown in the store dashboard:

- Up to 7 terms per language.
- Up to 30 characters per term.
- No more than 21 separate words across all terms for a language.

These terms are maintained separately from the extension's manifest and listing
descriptions. They must be entered manually in the store dashboard; saving this
file does not update a published listing.
