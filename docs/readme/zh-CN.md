## 快速开始

1. 打开 Netflix 视频。如果安装或重新加载扩展时 Netflix 已打开，请刷新该标签页。
2. 打开工具栏弹出窗口，确认“启用扩展”已开启；此开关默认开启，也可在此查看当前快捷键与兼容性状态。
3. 关闭弹出窗口，点击视频让播放器获得焦点，再试按 `Space` 播放／暂停，或 `Left`／`Right` 跳转。
4. 从快捷键分类点击“打开设置”，即可编辑该页按键与偏好。多数开关立即保存；编辑对话框则在点击“保存”后应用。

常规快捷键与 `2x` 长按变速默认启用。字幕导航、自动跳过、自动播放下一集与隐藏暂停遮罩需要自行开启。

## 主要功能

- 自定义快捷键、清空按键、单独启用或禁用，并在设置中处理按键冲突。
- 控制播放、逐帧移动、快进与快退、切换集数、音量、全屏及播放速度。
- 添加前进／后退组合、视频百分比跳转与常用倍速快捷键，并自定义字幕大小循环。
- 按自定义顺序切换常用字幕与音轨，并可单独选择口述影像音轨。
- 跳至上一句或下一句字幕，或重播当前句子。
- 在 Chrome 与 Edge 使用保留 Netflix 字幕、带播放控件的画中画。
- 长按播放／暂停键暂时调整速度，松开后恢复原速。
- 自动跳过片头、前情提要或播放下一集，并可隐藏 Netflix 暂停遮罩。
- 通过工具栏弹出窗口检查兼容性，并复制本地诊断信息。
- 通过浏览器存储同步设置、导出与导入备份，并提供五种界面语言与三种界面风格。

## 默认快捷键

以下按当前设置页的五个分类，列出全部 23 个内置操作。播放快捷键均可改键或禁用；升级会保留已保存的按键，当前设置请以弹出窗口为准。

### 播放

| 操作 | 默认按键 | 行为 |
| --- | --- | --- |
| 播放 / 暂停 | `Space` | 短按切换播放／暂停；长按临时变速。 |
| 上一集 | `Ctrl + P` | 通过 Netflix 集数菜单播放前一个可用集数。 |
| 下一集 | `Ctrl + N` | 使用 Netflix 的下一集控件或集数菜单。 |
| 全屏 | `F` | 切换 Netflix 页面的全屏；画中画内不适用。 |
| 画中画 | `Shift + P` | 打开／关闭保留字幕的画中画，需要 Chrome／Edge 116+。 |

### 进度与跳转

| 操作 | 默认按键 | 行为 |
| --- | --- | --- |
| 上一帧 | `,` | 先暂停，再退回一帧，移动后保持暂停。 |
| 下一帧 | `.` | 先暂停，再前进一帧，移动后保持暂停。 |
| 跳过片头 | `S` | 点击当前可见且能识别的 Netflix 跳过按钮，包含片头、前情提要或片尾。 |
| 快进 | `→` | 默认前进 10 秒；内置组合可设为 1–300 秒。 |
| 倒退 | `←` | 后退与前进相同的秒数。 |

### 字幕切换与大小

| 操作 | 默认按键 | 行为 |
| --- | --- | --- |
| 开启／关闭字幕 | `C` | 开关 Netflix 原生字幕，重新开启时恢复上次仍可用的字幕轨。 |
| 切换字幕大小 | `Shift + C` | 按 80% → 100% → 125% 循环；初始为 100%，第一次按下切至 125%。 |
| 切换到下一个字幕语言 | `Shift + X` | 切换下一个可用字幕／常用语言，到末尾后循环。 |
| 切换到上一个字幕语言 | `Shift + Z` | 切换上一个可用字幕／常用语言，到开头后循环。 |

### 音量与音轨

| 操作 | 默认按键 | 行为 |
| --- | --- | --- |
| 提高音量 | `↑` | 每次提高 5 个百分点。 |
| 降低音量 | `↓` | 每次降低 5 个百分点。 |
| 静音 | `M` | 切换静音状态。 |
| 上一种音轨语言 | `Shift + A` | 切换上一种可用音轨／常用音轨，包含口述影像版本。 |
| 下一种音轨语言 | `Shift + D` | 切换下一种可用音轨／常用音轨，包含口述影像版本。 |

### 播放速度

| 操作 | 默认按键 | 行为 |
| --- | --- | --- |
| 加快播放速度 | `Shift + .` | 默认每次提高 0.25x，受设置的速度上下限限制。 |
| 降低播放速度 | `Shift + ,` | 默认每次降低 0.25x，受设置的速度上下限限制。 |
| 重设播放速度 | `Shift + /` | 回到 1x。 |
| 应用常用倍速 | `Shift + Quote` | 应用设置的常用倍速，默认为 1.5x。 |

长按播放／暂停键约 250 毫秒会应用长按速度（默认 `2x`），松开后恢复原本速度与播放／暂停状态；改键后也会跟随新的播放／暂停键。长按跳转或逐帧键可重复移动，逐帧准确度取决于 Netflix。切换轨道、字幕大小循环、常用倍速、百分比跳转与切换集数均为每次按下执行一次。

macOS 的 `Ctrl + P`／`Ctrl + N` 同样指 Control，可能被浏览器保留，必要时请改键。快捷键以物理按键位置与修饰键判定；`Quote` 指引号键（美式键盘的 `'`／`"`），弹出窗口可能显示为 `Shift + "`。另有四个需单独启用的[逐句字幕操作](#字幕导航)，以及可在[设置](#设置与自定义)添加的自定义快捷键。

### 设置界面快捷键

以下用于扩展界面，与可自定义的 Netflix 播放按键分开。

| 操作 | macOS | Windows／Linux |
| --- | --- | --- |
| 聚焦设置页或弹出窗口的搜索栏 | `⌘ + K` | `Ctrl + K` |
| 按侧边栏顺序切换设置页 | `⌘ + 1`–`⌘ + 9` | `Ctrl + 1`–`Ctrl + 9` |

## 设置与自定义

从设置页侧边栏“备份与恢复”下方，或弹出窗口底部打开“使用说明”，即可查看支持五种界面语言、可搜索与展开收起的操作说明。共 11 项精简说明，分为“开始使用”、“快捷键设置”、“备份与恢复”、“权限与隐私”四类，并提供前往相关设置的链接。各项功能提示位于对应控件旁；完整功能参考请见[详细使用指南（英文）](../user-guide.md)。

从设置页侧边栏选择快捷键分类、常规设置、播放偏好，或备份与恢复。可跨五种界面语言搜索设置、功能名称、语言名称或按键。工具栏弹出窗口提供可搜索的快捷键参考与兼容性状态；点击“打开设置”会进入对应的设置页编辑。

- **进度与跳转：**内置与自定义前进／后退组合均可设为 1–300 秒，两个方向分别设置按键；也可添加跳至视频 0–100% 位置的快捷键。升级时，旧有超过 300 秒的自定义组合会调整为 300 秒并保留按键。
- **字幕大小：**修改默认的 80% → 100% → 125% 循环，使用 2–6 个不同的 50–300% 整数百分比，并拖动调整顺序。100% 恢复原始大小；缩放只在本地应用，不会更改 Netflix 帐号偏好。常规播放与画中画分别保存当前大小；先前保存的较长循环会保留，固定大小及额外循环快捷键仍可编辑或删除。
- **播放速度：**添加 `0.25x` 至 `5x` 的常用倍速快捷键，同时编辑速度与按键。长按倍速位于播放／暂停下方，速度上下限与调整幅度则位于播放速度页。
- **常用字幕与音轨：**批量添加字幕语言或音轨，再拖动调整切换顺序；口述影像音轨可单独选择。快捷键会跳过当前视频未提供的项目；列表为空时则切换所有可用轨道。常用列表只影响快捷键切换，打开视频时不会自动改变轨道。
- **本页功能：**使用“管理本页功能”隐藏不需要的控件并禁用对应快捷键，同时保留按键与参数。重新显示时，没有按键冲突的快捷键会启用。也可在编辑器中清空按键，保存为“未设置”。
- **外观：**选择 Classic 或 Neobrutalism 界面风格，并单独设置浅色、深色或跟随系统。已有或导入的 Markdown 设置仍会正确应用和显示，切换到其他风格后才会隐藏。

自定义前进／后退组合、百分比跳转与额外常用倍速默认均为空列表，没有固定默认按键，添加时自行指定。长按变速共用播放／暂停键；自动跳过与自动播放下一集则使用开关，不另配快捷键。

在“播放偏好 → 自动播放与跳过”中，可分别启用片头、前情提要或下一集；Netflix 显示对应按钮时，扩展会自动点击。在“播放偏好 → 暂停画面”启用“隐藏暂停遮罩”，可隐藏暂停时的节目名称、简介与黑色遮罩，保留字幕和播放控制栏。这些选项均默认关闭。

### 改键与处理冲突

点击行上的铅笔，录制按键组合后点击“保存”。选择“添加快捷键”可保留原按键并添加其他组合，每个操作最多三组。按键可逐组移除；保存时会忽略空栏，并以第一组剩余按键作为主按键。清空或移除全部按键后保存，才会成为“未设置”。

如果其他已启用的操作占用按键，可改用其他组合，或明确转移按键；转移会禁用原操作，如果属于前进／后退组合则两个方向都会禁用。同一操作的所有按键共用启用状态；禁用后仍保留完整列表，并释放按键供其他操作使用。设置页、弹出窗口、搜索及备份都包含所有已设置按键。

如果浏览器能将媒体键事件发送到录制栏，可在 `Ctrl+N` 旁添加 `MediaTrackNext`，或在 `Ctrl+P` 旁添加 `MediaTrackPrevious`。播放时，已设置的曲目键也会通过浏览器 Media Session 控制处理；被操作系统或浏览器拦截的按键可能无法录制。

已分配的播放／暂停、停止、快进与后退键，也支持浏览器 Media Session 控制。绑定“播放／暂停”功能时，播放指令只播放，暂停或停止指令只暂停，不启动长按倍速。未分配的控制交由 Netflix 处理；音量键仍需浏览器发送键盘事件。

浏览器传入完整键盘事件时，媒体键可搭配 Ctrl、Alt、Shift 或 Command／Win。例如 `Ctrl+MediaTrackNext` 与单按 `MediaTrackNext` 是不同快捷键；同一次操作的键盘与媒体通知只执行实际按下的组合。所有经扩展处理的独立浏览器媒体通知都会等待最多 120ms，再使用单按设置或交由 Netflix 处理，不会推测修饰键。键盘事件会立即确认实际分配；较早的播放操作可能等待较新的媒体通知确认功能后才执行。即使只设置单按，未分配的组合键也不会误触单按功能。

将播放／暂停、快进等支持的 Netflix 原生快捷键改键后，只有在操作启用、至少设置一组按键，且列表不再保留原按键时，才会拦截原本的 Netflix 按键。禁用操作、清空全部按键或关闭扩展会解除这项拦截。

例如可添加 90 秒的前进／后退组合、跳至视频 50% 的按键，或分别设置 `1.25x` 与 `2x` 常用倍速键。自定义项目可单独编辑、禁用或删除。

### 播放速度默认值

| 设置 | 默认值 | 可设置范围 |
| --- | --- | --- |
| 最低速度 | `0.25x` | `0.25x`–`1x` |
| 最高速度 | `3x` | `1x`–`5x` |
| 调整幅度 | `0.25x` | `0.05x`–`5x` |
| 常用倍速 | `1.5x` | `0.25x`–`5x` |
| 长按倍速 | `2x` | `0.25x`–`5x` |

速度以 `0.05x` 为单位调整。长按变速与提示可分别切换；长按期间使用其他倍速快捷键，松开播放／暂停键后会保留新速度。重置播放速度会回到 `1x`。

如果要用加快速度键调到 `5x`，请在“播放速度 → 范围与调整幅度”将“最高倍速”设为 `5x`。如果要直接应用 `5x`，可编辑内置常用倍速，或添加常用倍速快捷键，再一起保存速度与按键。

## 字幕导航

字幕导航**默认关闭**：

1. 打开设置，开启“启用扩展程序”。
2. 进入“快捷键 → 字幕 → 逐句跳转与重播”，开启“启用”，并在浏览器提示时允许 Netflix 与字幕来源的网站访问权限。
3. 在 Netflix 选择字幕轨。

| 操作 | 默认按键 | 行为 |
| --- | --- | --- |
| 上一句 | `A` | 跳到前一句的开始，保持播放／暂停状态。 |
| 下一句 | `D` | 跳到下一句的开始，保持播放／暂停状态。 |
| 重播当前句子 | 未设置（默认停用） | 自行配键并启用后，跳到当前句子的开始并播放一次。 |
| 播放／暂停 | `W` | 立即切换播放状态，不启用长按变速。 |

`A`、`D` 保持原本的播放或暂停状态。重播功能从当前字幕开始播放，不会循环或在句尾自动停止。`W` 立即切换播放状态，不会启用长按变速。

**字幕导航不会覆盖常规快捷键。**已启用的快捷键会保留按键；请为字幕导航改键，或在冲突提示中明确转移归属。已有重复设置会保留常规快捷键，`S` 会继续跳过片头，直到明确重新分配。

拒绝网站授权时，字幕导航会保持关闭；再次开启即可重试。这些按键也可在 Chrome 与 Edge 的扩展画中画窗口中使用。

时间信息会在使用时按当前视频与字幕轨加载。第一次跳转可能显示加载提示；切换集数或字幕轨后会重新加载。导航使用当前选择的字幕，不会自行更改语言。

## 画中画

在 Chrome 或 Edge 116+ 打开 Netflix 视频后，按 `Shift + P` 进入保留字幕的画中画。再按一次或关闭窗口可将视频放回 Netflix；使用期间请保持来源标签页打开。

- 可调整浮动窗口大小，视频会保持宽高比。
- 点击视频即可播放／暂停，也可用控制栏跳转、静音、调整音量，或点击／拖动进度条。鼠标停止移动三秒后，控制栏会隐藏。
- 字幕菜单与 Netflix 的字幕开关同步，并可选择字幕大小及无背景、半透明或深色背景；显示内容来自当前选择的 Netflix 字幕。
- 画中画视频获得焦点时，也可使用播放快捷键与已启用的字幕导航键；全屏则在来源 Netflix 页面使用。
- 检测到集数切换后，画中画会关闭并回到 Netflix 播放；下一集需要再次打开画中画。

Firefox 内置的画中画是另一项功能；本扩展的画中画快捷键与字幕控件在 Firefox 中禁用。

## 备份、同步与重置

设置保存在浏览器同步存储中。跨设备同步取决于浏览器帐号与同步设置；跨浏览器、配置文件，或商店与手动安装版本之间，可使用 JSON 备份迁移。

1. 打开“设置 → 备份与恢复 → 导出设置”，下载包含按键、启用状态、自定义项目、常用轨道、外观与播放偏好的 JSON 文件。
2. 在目标安装版本选择“导入设置”，并选取文件。
3. 检查摘要后确认。导入会**替换**当前设置；支持的旧备份会自动转换，格式错误或不支持的新版文件会在替换前被拒绝。如果需要恢复到原有设置，请先导出目标端的设置。

各重置控件的范围不同：

- **恢复默认值：**在“备份与恢复”确认后，会重置全部设置，包括自定义快捷键、常用轨道、隐藏功能、语言、主题与界面风格。如果需要保留偏好，请先导出备份。
- **重置常规快捷键：**恢复所有常规快捷键的按键与启用状态，移除自定义跳转、常用倍速及字幕大小项目，并恢复字幕大小循环；字幕导航按键及其他偏好保持原值。
- **重置字幕导航：**恢复四行快捷键并保留主开关；如果默认按键已被启用的常规快捷键占用，该行会保持禁用。
- 单个设置的重置范围较小，例如只恢复跳转秒数、速度上下限与幅度，或长按变速设置；确认前可查看重置说明。

## 界面语言

支持英文、繁体中文、简体中文、日文与韩文。可自动跟随支持的浏览器界面语言，或在设置中手动选择。

## 浏览器支持与限制

- 支持桌面版 Chrome 111+、Edge 111+ 与 Firefox 128+。保留字幕的画中画需使用 Chrome 或 Edge 116+；Firefox 中此功能禁用。
- 快捷键只在 Netflix 观看页面或显示播放器的页面运行；在可编辑字段输入时不会拦截按键。
- 全屏只适用于 Netflix 页面。跳过片头需要有可见的 Netflix 跳过按钮。
- 跳转、字幕切换与字幕导航依赖 Netflix 未公开的播放器接口，Netflix 更新后可能需要调整扩展。

## 权限与隐私

- **Netflix 网站访问权限：**执行播放快捷键并读取当前选择的字幕轨。
- **可选的 `https://*.nflxvideo.net/*` 访问权限：**启用字幕导航时请求授权，使用导航时下载字幕文件；不会在此 CDN 网站运行内容脚本。
- **存储、脚本执行及当前标签页：**保存设置、执行播放操作、检查兼容性及恢复播放焦点。只有选择恢复操作时，弹出窗口才会重新加载 Netflix。

关闭字幕导航不会撤销已授予的网站访问权限。详见[权限说明（英文）](../user-guide.md#permissions)与[授权问题排查（英文）](../troubleshooting.md#subtitle-website-access)。

不使用流量分析、跟踪或第三方处理服务。字幕从 Netflix 分发主机下载并在本地解析，时间缓存只保留在内存中；设置使用浏览器同步存储。兼容性诊断保留在设备上，除非你自行复制并分享。完整政策请见[隐私政策（英文）](../../PRIVACY.md)。

## 问题排查

- **按键没有反应：**确认全局与单个操作开关已启用，关闭弹出窗口并让视频获得焦点。在文本字段输入时不会拦截按键；当前按键可在弹出窗口查看。
- **显示未启用或仍在检查：**如果提供“重新加载 Netflix”，可使用此恢复功能。Netflix 仍在加载时，弹出窗口会自动重新检查兼容性，请等待播放器就绪。
- **字幕导航无法加载：**先选择 Netflix 字幕轨，再关闭并重新开启字幕导航以重试网站授权。Firefox 也可检查扩展的“权限与数据”页面。
- **常用轨道被跳过：**当前视频必须提供该轨道；全部不符合时会保持原选择。清空常用列表即可切换所有可用轨道。
- **无法使用画中画：**请使用 Chrome／Edge 116+ 并打开实际播放的视频；本扩展的画中画在 Firefox 中禁用。

授权恢复与开发问题请见[问题排查指南（英文）](../troubleshooting.md)。反馈播放器或 API 问题时，可附上弹出窗口的兼容性诊断信息。

## 开发与文档

需要 Node.js 22.18.0 以上与 npm。在项目根目录执行：

```sh
npm ci
npm run build
```

Chrome／Edge 加载 `dist/chromium`；Firefox 以临时附加组件加载 `dist/firefox/manifest.json`。

`npm run build` 会检查类型、构建两种浏览器版本，并验证生成的后台程序入口。Chromium 开发时执行 `npm run dev`，改为加载 `dist` 并保持 HMR 服务器运行。修改 manifest、后台程序或内容脚本注册后，请重新加载扩展与 Netflix 标签页。

自动化检查：

```sh
npm run lint
npm run test:coverage
npm run build
npm run lint:firefox
```

自动化检查使用受控的浏览器与播放器替身；Netflix 实际播放、授权与集数切换仍需要执行下方链接中的浏览器验收。
