Netflix の再生ショートカットをカスタマイズし、字幕に沿って移動したり、字幕付きピクチャーインピクチャーで視聴したりできます。

非公式の拡張機能です。Netflix との提携関係はなく、Netflix による承認や支援も受けていません。

ブラウザーのストアからインストールし、Netflix の動画を開いてください。ツールバーの拡張機能アイコンから状態を確認したり、設定を開いたりできます。

手動でインストールする場合は、[GitHub Releases](https://github.com/chenghsj/netflix-shortcut-override/releases/latest) からブラウザーに合ったパッケージをダウンロードしてください。

- **Chrome / Edge：**Chromium ZIP を展開し、`chrome://extensions` または `edge://extensions` でデベロッパーモードを有効にします。「パッケージ化されていない拡張機能を読み込む」を選び、`manifest.json` を含むフォルダーを指定します。
- **Firefox：**`about:debugging#/runtime/this-firefox` で「一時的なアドオンを読み込む」を選び、Firefox ZIP を指定します。ブラウザーを再起動すると削除されます。継続して使用し、自動更新を受けるには Firefox Add-ons からインストールしてください。

インストールには名前に `chromium` または `firefox` を含む ZIP を選んでください。`source` ZIP はソースからのビルド用です。ベータ版は[リリース一覧](https://github.com/chenghsj/netflix-shortcut-override/releases)のプレリリースから選べます。[ベータ版のインストール方法（英語）](../release.md#beta-releases)もご覧ください。手動版を試すときは、キーが二重に処理されないよう、別にインストールした同じ拡張機能を無効にしてください。設定はバックアップで移せます。

この README は現在のソースの機能を説明しています。ストア版や安定版には一部の機能が含まれない場合があるため、インストールする版のリリースノートをご確認ください。

## 使い始める

1. Netflix の動画を開きます。拡張機能のインストールや再読み込み前から開いていたタブは更新してください。
2. ツールバーのポップアップで拡張機能が有効になっていることを確認します。既定では有効です。保存済みのキーと互換性の状態も確認できます。
3. ポップアップを閉じ、動画をクリックしてフォーカスを戻します。`Space` で再生／一時停止、`Left` / `Right` でシークを試せます。
4. カテゴリ内の「設定を開く」からキーや設定を編集します。多くのスイッチは即座に保存され、編集ダイアログの変更は「保存」で適用されます。

通常のショートカットと `2x` の長押し速度は既定で有効です。字幕ナビゲーション、自動スキップ、次のエピソードの自動再生、オーバーレイの非表示は個別に有効にしてください。

## 主な機能

- ショートカットの変更、キー割り当ての解除、有効・無効の切り替え、キーの競合解決。
- 再生、コマ送り・コマ戻し、シーク、エピソードの切り替え、音量、全画面、再生速度の操作。
- シークのペア、再生位置（%）への移動、好みの再生速度のキーを追加。字幕サイズの切り替えリストも編集可能。
- お気に入りの字幕・音声トラックを指定した順序で切り替え。音声ガイド付きトラックも個別に選択可能。
- 前後の字幕への移動と、現在の字幕からの再生。
- Chrome と Edge で、Netflix の字幕と再生コントロールを備えたピクチャーインピクチャー。
- 再生／一時停止キーを長押しすると一時的に速度を変更し、離すと元の速度に戻す機能。
- イントロ・あらすじの自動スキップ、次のエピソードの自動再生、一時停止中のオーバーレイの非表示。
- ツールバーのポップアップで互換性を確認し、ローカルの診断情報をコピー。
- ブラウザーのストレージによる設定の同期、バックアップのエクスポート・インポート、10 言語と 3 種類の表示スタイル。

## 既定のショートカット

現在の設定画面の 5 カテゴリに沿って、全 23 個の組み込み操作を示します。再生キーは変更・無効化できます。アップグレードは保存済みの割り当てを保持するため、現在のキーはポップアップで確認してください。

### 再生

| 操作 | 既定のキー | 動作 |
| --- | --- | --- |
| 再生 / 一時停止 | `Space` | 短押しで再生／一時停止、長押しで一時的な速度変更。 |
| 前のエピソード | `Shift + P` | Netflix のエピソード一覧で前の利用可能な回を再生。 |
| 次のエピソード | `Shift + N` | Netflix の次のエピソード操作または一覧を使用。 |
| 全画面 | `F` | Netflix ページの全画面切り替え。PiP 内では使用不可。 |
| ピクチャー イン ピクチャー | `P` | 字幕付き PiP の開閉。Chrome / Edge 116 以降が必要。 |

### 再生位置・ジャンプ

| 操作 | 既定のキー | 動作 |
| --- | --- | --- |
| 前のフレーム | `,` | 一時停止して 1 フレーム戻り、停止を維持。 |
| 次のフレーム | `.` | 一時停止して 1 フレーム進み、停止を維持。 |
| イントロをスキップ | `S` | 認識できる表示中の Netflix スキップボタンを押す。イントロ・あらすじ・クレジットが対象。 |
| 進む | `→` | 既定で 10 秒進む。組み込みの間隔は 1～300 秒。 |
| 戻る | `←` | 早送りと同じ秒数戻る。 |

### 字幕の切替・サイズ

| 操作 | 既定のキー | 動作 |
| --- | --- | --- |
| 字幕のオン／オフ | `C` | Netflix 字幕をオン／オフ。利用可能なら前回のトラックを復元。 |
| 字幕サイズを切り替え | `Shift + C` | 80% → 100% → 125% の順に切り替え。初期値は 100% で、最初の操作は 125%。 |
| 次の字幕言語 | `Shift + X` | 次の利用可能な字幕／お気に入りへ。末尾で循環。 |
| 前の字幕言語 | `Shift + Z` | 前の利用可能な字幕／お気に入りへ。先頭で循環。 |

### 音量・音声

| 操作 | 既定のキー | 動作 |
| --- | --- | --- |
| 音量を上げる | `↑` | 音量を 5 パーセントポイント上げる。 |
| 音量を下げる | `↓` | 音量を 5 パーセントポイント下げる。 |
| ミュート | `M` | ミュートを切り替え。 |
| 前の音声言語 | `Shift + A` | 前の音声／お気に入りへ。音声ガイド付きも対象。 |
| 次の音声言語 | `Shift + D` | 次の音声／お気に入りへ。音声ガイド付きも対象。 |

### 再生速度

| 操作 | 既定のキー | 動作 |
| --- | --- | --- |
| 再生速度を上げる | `Shift + .` | 既定で 0.25x 上げる。設定した速度範囲内で変更。 |
| 再生速度を下げる | `Shift + ,` | 既定で 0.25x 下げる。設定した速度範囲内で変更。 |
| 再生速度をリセット | `Shift + /` | 1x に戻す。 |
| よく使う速度に設定 | `Shift + Quote` | 設定した好みの速度を適用。既定は 1.5x。 |

再生／一時停止を約 250 ミリ秒長押しすると長押し速度（既定 `2x`）を使用し、離すと元の速度と再生／停止状態に戻ります。キーを変更しても同じ動作です。シークとフレーム移動は長押しで繰り返せますが、フレーム精度は Netflix に依存します。トラック・字幕サイズ・好みの速度・再生位置（%）・エピソードのキーは 1 回の押下につき 1 回動作します。

割り当ては物理キーと修飾キーで判定します。`Quote` は引用符キー（US 配列の `'` / `"`）で、ポップアップでは `Shift + "` と表示される場合があります。別途有効にする 4 個の[字幕移動キー](#字幕ナビゲーション)と、[設定](#設定とカスタマイズ)で追加するキーもあります。

### 設定画面のショートカット

拡張機能の画面用です。変更可能な Netflix の再生キーとは別です。

| 操作 | macOS | Windows / Linux |
| --- | --- | --- |
| 設定画面またはポップアップの検索欄へ移動 | `⌘ + K` | `Ctrl + K` |
| サイドバーの順に設定ページを切り替え | `⌘ + 1`–`⌘ + 9` | `Ctrl + 1`–`Ctrl + 9` |

設定画面の 1～9 は、再生、再生位置・ジャンプ、字幕、音量・音声、再生速度、一般設定、再生設定、バックアップ・復元、使い方の順です。`⌘` / `Ctrl` を約 300 ミリ秒長押しすると番号を表示します。`Esc` で検索を消去します。編集ダイアログやキー記録中はページ切り替えを実行しません。

## 設定とカスタマイズ

設定のサイドバーで「バックアップ・復元」の下にある「使い方」、またはポップアップ下部のボタンを選ぶと、10 言語対応の検索・折りたたみ可能な操作説明を開けます。11 項目の簡潔な説明を「使い始める」「ショートカット設定」「バックアップと復元」「権限とプライバシー」の 4 カテゴリにまとめ、関連する設定へのリンクも用意しています。各機能のヒントは対応する操作項目のそばに表示します。詳しい機能説明は[詳細な使い方（英語）](../user-guide.md)をご覧ください。

設定のサイドバーからショートカットのカテゴリ、一般設定、再生設定、バックアップ・復元を選択できます。設定、機能名、言語名、キーを 10 言語で横断検索できます。ツールバーのポップアップではショートカットの検索と互換性の確認ができ、「設定を開く」から対応する設定ページを開いて編集できます。

- **再生位置への移動：**組み込み・追加のシークペアはすべて 1～300 秒で設定でき、前後のキーを個別に指定します。動画の 0～100% の位置に移動するキーも追加できます。以前の 300 秒を超えるペアは、更新時にキーを保持したまま 300 秒に調整します。
- **字幕サイズ：**既定の 80% → 100% → 125% のリストを、50～300% の異なる整数サイズ 2～6 個で編集し、ドラッグで並べ替えられます。100% は元のサイズです。変更はローカルの表示に適用し、Netflix アカウントの設定は変更しません。通常再生と PiP のサイズは別々に保存されます。以前に保存した長いリストは保持し、固定サイズや追加リストのキーも引き続き編集・削除できます。
- **再生速度：**`0.25x`～`5x` の好みの速度を追加し、速度とキーをまとめて編集できます。長押し速度は再生／一時停止の下、速度の上下限と変更幅は再生速度ページにあります。
- **お気に入りの字幕・音声：**字幕言語や音声トラックをまとめて追加し、ドラッグで切り替え順を指定できます。音声ガイド付きトラックは個別に選択できます。利用できないお気に入りはスキップし、リストが空ならすべての利用可能なトラックを切り替えます。動画を開いた時点でトラックを自動変更することはありません。
- **ページの機能：**「このページの機能を管理」で不要な項目を非表示にし、対応するショートカットを無効にできます。キーと設定値は保持され、再表示時はキーが競合しなければ有効になります。編集画面でキーを消去して「未設定」として保存することもできます。
- **外観：**Classic または Neobrutalism と、ライト・ダーク・システム連動の明るさを個別に選択できます。既存・インポート済みの Markdown は正しく表示され、別のスタイルに切り替えるまで保持されます。

追加のシークペア、再生位置（%）、好みの速度は初期状態では空で、既定のキーはありません。追加時に割り当てます。長押し速度は再生／一時停止と同じキーを使います。自動スキップと次のエピソードの自動再生は、追加キーではなくスイッチで操作します。

「再生設定」では、「イントロを自動スキップ」「あらすじを自動スキップ」「次のエピソードを自動再生」を個別に有効にできます。Netflix に対応するボタンが表示されると自動でクリックします。「一時停止中のオーバーレイを非表示」は、タイトル、あらすじ、暗い背景を隠し、字幕と再生コントロールを表示したままにします。これらの設定はすべて既定ではオフです。

### キーの編集と競合の解決

行の鉛筆を選び、キーの組み合わせを入力して「保存」を選択します。「ショートカットを追加」で既存のキーを残して別の組み合わせを追加でき、1 つの操作につき最大 3 組まで設定できます。キーは個別に削除でき、保存時に空欄を除き、残った最初のキーを主キーにします。未設定にするには、すべてのキーを消去または削除して保存してください。

有効な別の操作が使用中のキーは、別の組み合わせに変えるか、明示的に割り当てを移してください。移すと元の操作が無効になり、シークペアの場合は両方向が無効になります。同じ操作のすべてのキーは有効状態を共有します。無効な行はキーの一覧を保持し、他の操作で再利用できます。設定、ポップアップ、検索、バックアップはすべての割り当て済みキーを扱います。

ブラウザーが記録欄にメディアキーのイベントを届ける場合、`Shift+N` に `MediaTrackNext`、`Shift+P` に `MediaTrackPrevious` を追加できます。再生中は、割り当て済みのトラックキーをブラウザーの Media Session 操作からも処理します。OS やブラウザーが消費するキーは記録できない場合があります。

割り当て済みの再生／一時停止、停止、早送り、巻き戻しキーも、ブラウザーの Media Session 操作に対応します。再生／一時停止の機能に割り当てた場合、再生指令は再生し、一時停止・停止指令は一時停止するだけで、長押し速度を開始しません。未割り当ての操作は Netflix が処理します。音量キーには引き続きキーボードイベントが必要です。

ブラウザーが完全なキーボードイベントを渡す場合、メディアキーを Ctrl、Alt、Shift、Command／Win と組み合わせられます。`Ctrl+MediaTrackNext` と `MediaTrackNext` 単独は別のショートカットです。同じ操作のキーボード通知とメディア通知では、実際に押した組み合わせだけを実行します。拡張機能が処理するブラウザーだけの操作は、すべて最大 120ms 待ち、単独キーの割り当て、または Netflix の処理を使います。修飾キーは推測しません。キーボード入力はすぐに処理し、単独キーだけの設定でも、未割り当ての組み合わせがその操作を実行することはありません。 古い再生操作は、新しいメディア通知の機能が確定するまで待機する場合があります。

再生／一時停止や早送りなど、対応する Netflix のキーを変更すると、操作が有効でキーが割り当てられており、一覧に元のキーが残っていない場合に限り、元の Netflix キーを抑止します。操作を無効にする、すべてのキーを消去する、拡張機能をオフにすると、この抑止を解除します。

例えば、90 秒のシークペア、50% の位置への移動、`1.25x` と `2x` の個別の速度キーを追加できます。追加した項目は個別に編集・無効化・削除できます。

### 再生速度の既定値

| 設定 | 既定値 | 設定範囲 |
| --- | --- | --- |
| 最低速度 | `0.25x` | `0.25x`–`1x` |
| 最高速度 | `3x` | `1x`–`5x` |
| 変更幅 | `0.25x` | `0.05x`–`5x` |
| 好みの速度 | `1.5x` | `0.25x`–`5x` |
| 長押し速度 | `2x` | `0.25x`–`5x` |

速度は `0.05x` 単位です。長押し速度とヒントは個別に切り替えられます。長押し中に別の速度キーを使うと、再生／一時停止キーを離しても新しい速度を保持します。速度のリセットは `1x` に戻します。

速度を上げるキーで `5x` まで使うには、再生速度の「速度範囲と変更幅」で最高速度を `5x` に設定してください。直接 `5x` にするには、既存の好みの速度を編集するか、新しい速度キーを追加し、速度とキーを保存します。

## 字幕ナビゲーション

字幕ナビゲーションは**既定ではオフ**です。

1. 設定を開き、拡張機能を有効にします。
2. ショートカットの「字幕」ページ内にある「字幕の移動・リピート」を開き、「有効にする」をオンにします。確認された場合は Netflix と字幕配信サイトへのアクセスを許可します。
3. Netflix で字幕トラックを選択します。

| 操作 | 既定のキー | 動作 |
| --- | --- | --- |
| 前の字幕 | `A` | 前の字幕の開始へ移動し、再生／停止状態を維持。 |
| 次の字幕 | `D` | 次の字幕の開始へ移動し、再生／停止状態を維持。 |
| 現在の字幕を再生 | 未設定（初期状態は無効） | キーを割り当てて有効にすると、現在の字幕の開始から 1 回再生。 |
| 再生／一時停止 | `W` | 長押し速度を使わず、すぐに再生状態を切り替え。 |

`A` と `D` は再生中・一時停止中の状態を維持します。「現在の字幕を再生」は現在の字幕の開始位置から再生します。ループ再生や字幕の終わりでの自動停止は行いません。`W` は即座に再生状態を切り替え、長押し速度は適用しません。

**字幕ナビゲーションは通常のショートカットを上書きしません。**使用中のキーは別のキーに変更するか、競合ダイアログで明示的に割り当てを移してください。既存の重複設定では通常のショートカットが有効なままで、`S` は再割り当てされるまでイントロをスキップします。

サイトへのアクセスを拒否した場合、機能はオフのままです。再度有効にして許可を要求できます。これらのキーは Chrome と Edge の拡張機能が管理するピクチャーインピクチャーウィンドウでも使えます。

時間情報は現在の動画と字幕トラックに応じて必要なときに取得します。最初の移動時は読み込み表示が出る場合があります。エピソードや字幕トラックを変えると再取得します。字幕の言語は変更しません。

## ピクチャーインピクチャー

Chrome または Edge 116 以降で Netflix の動画を開き、`P` を押すと字幕付き PiP に入ります。もう一度押すかウィンドウを閉じると動画を Netflix に戻します。元のタブは開いたままにしてください。

- ウィンドウをリサイズしても動画の縦横比を維持します。
- 動画のクリックで再生／一時停止し、コントロールでシーク・ミュート・音量調整ができます。タイムラインのクリックやドラッグにも対応します。ポインターを 3 秒間操作しないとコントロールは隠れます。
- 字幕メニューは Netflix の字幕のオン／オフと同期し、字幕サイズと背景なし・半透明・濃い背景を選べます。選択中の Netflix 字幕を表示します。
- PiP の動画にフォーカスがあるときは再生キーや有効な字幕ナビゲーションキーも使えます。全画面は元の Netflix ページで利用できます。
- エピソードの切り替えを確認すると PiP が閉じ、Netflix に再生を戻します。次のエピソードでは PiP を開き直してください。

Firefox 内蔵の PiP は別の機能です。この拡張機能の PiP キーと字幕コントロールは Firefox では無効です。

## バックアップと同期

設定はブラウザーの同期ストレージに保存します。端末間の同期はブラウザーのアカウントと同期設定に依存します。ブラウザー、プロファイル、ストア版・手動版の間では JSON バックアップで移せます。

1. 設定のバックアップ・復元ページから書き出すと、キー、有効状態、追加項目、お気に入り、外観、再生設定を含む JSON ファイルをダウンロードします。
2. 移行先で設定の読み込みを選び、ファイルを指定します。
3. 概要を確認して確定します。読み込みは現在の設定を**置き換えます**。対応する古いバックアップは変換され、不正なファイルや未対応の新しい形式は置き換え前に拒否されます。元に戻せるよう、先に移行先の設定を書き出してください。

リセットには範囲の違いがあります。

- **初期設定に戻す：**バックアップ・復元ページで確認すると、追加したショートカット、お気に入り、非表示の機能、言語、テーマ、表示スタイルを含むすべての設定を戻します。保持したい設定は先にバックアップを書き出してください。
- **一般ショートカットのリセット：**通常のキーと有効状態を戻し、追加したシーク・速度・字幕サイズの項目を削除し、字幕サイズのリストを戻します。字幕ナビゲーションのキーや他の設定は保持します。
- **字幕ナビゲーションのリセット：**4 行を戻し、マスタースイッチを保持します。通常の有効なキーと重なる既定の行は無効になります。
- 個別のリセットは、シーク間隔のみ、速度の上下限と変更幅のみ、長押し設定のみなど、対象が限られます。確認前に説明をご覧ください。

## 表示言語

英語、繁体字中国語、簡体字中国語、日本語、韓国語、スペイン語、ポルトガル語（ブラジル）、フランス語、ドイツ語、インドネシア語に対応しています。対応するブラウザーの表示言語に自動で合わせるか、設定で手動選択できます。

## 対応ブラウザーと制限

- デスクトップ版 Chrome 111 以降、Edge 111 以降、Firefox 128 以降に対応しています。字幕付きピクチャーインピクチャーは Chrome または Edge 116 以降が必要で、Firefox では無効です。
- ショートカットは Netflix の視聴ページやプレーヤーが表示されているページで動作します。入力欄などでの文字入力中はキーを処理しません。
- 全画面は Netflix ページでのみ利用できます。イントロのスキップには Netflix のスキップボタンが表示されている必要があります。
- シーク、字幕切り替え、字幕ナビゲーションは Netflix の非公開プレーヤーインターフェースに依存するため、Netflix の変更に伴い拡張機能の更新が必要になる場合があります。

## 権限とプライバシー

- **Netflix サイトへのアクセス：**再生ショートカットの実行と、選択中の字幕トラックの読み取りに使用します。
- **任意の `https://*.nflxvideo.net/*` へのアクセス：**字幕ナビゲーションを有効にする際に許可を要求し、移動操作時に字幕文書を取得します。この CDN サイトではコンテンツスクリプトを実行しません。
- **ストレージ、スクリプト実行、アクティブなタブ：**設定の保存、再生操作、互換性の確認、再生画面へのフォーカス復元に使用します。Netflix の再読み込みは、ポップアップで復旧操作を選択した場合にのみ行います。

字幕ナビゲーションを無効にしても、許可済みのサイトアクセスは取り消されません。[権限の詳細（英語）](../user-guide.md#permissions)と[アクセス権限のトラブルシューティング（英語）](../troubleshooting.md#subtitle-website-access)をご覧ください。

アクセス解析、追跡、第三者による処理サービスは使用しません。字幕文書は Netflix の配信ホストから取得してローカルで解析し、時間情報のキャッシュはメモリ内にのみ保持します。設定はブラウザーの同期ストレージに保存します。互換性の診断情報は、自分でコピーして共有しない限り端末内に留まります。詳しくは[プライバシーポリシー（英語）](../../PRIVACY.md)をご覧ください。

## トラブルシューティング

- **キーが反応しない：**全体と個別の操作が有効か確認し、ポップアップを閉じて動画にフォーカスを戻してください。入力欄ではキーを処理しません。現在の割り当てはポップアップで確認できます。
- **未接続や確認中の表示：**Netflix の再読み込みが提示されたら利用できます。動画の読み込み中は互換性を自動で再確認するため、プレーヤーの準備を待ってください。
- **字幕ナビゲーションが読み込めない：**Netflix の字幕を選び、機能をオフ・オンにしてサイトアクセスを再要求してください。Firefox では拡張機能の権限とデータのページも確認してください。
- **お気に入りがスキップされる：**その動画に対象トラックが必要です。一致しなければ選択は変わりません。リストを空にすると全トラックを切り替えます。
- **PiP が使えない：**Chrome / Edge 116 以降で再生動画を開いてください。この拡張機能の PiP は Firefox では無効です。

権限の復旧や開発時の問題は[トラブルシューティング（英語）](../troubleshooting.md)をご覧ください。プレーヤーや API の不具合報告にはポップアップの診断情報を添えてください。

## 開発とドキュメント

Node.js 22.18.0 以上と npm が必要です。リポジトリのルートで実行します。

```sh
npm ci
npm run build
```

Chrome / Edge では `dist/chromium` を、Firefox では `dist/firefox/manifest.json` を一時的なアドオンとして読み込みます。

`npm run build` は型チェック、両ブラウザー向けのビルド、生成されたバックグラウンドのエントリーポイントの検証を行います。Chromium の開発時は `npm run dev` を実行し、`dist/chromium` の代わりに `dist` を読み込んで HMR サーバーを起動したままにします。manifest、バックグラウンド、コンテンツスクリプトの登録を変更したら、拡張機能と Netflix タブを再読み込みしてください。

自動チェック：

```sh
npm run lint
npm run test:coverage
npm run build
npm run lint:firefox
```

自動チェックは制御されたブラウザー・プレーヤーの代替を使用します。実際の Netflix 再生、権限、エピソード切り替えは、下記のブラウザーテストでも確認してください。
